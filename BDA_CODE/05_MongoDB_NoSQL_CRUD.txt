NOSQL FEATURES AND MONGODB CRUD COMMANDS

NOSQL FEATURES
1. Flexible/schema-less data model
2. Horizontal scalability
3. High availability
4. Distributed architecture
5. Fast read/write operations
6. Handles large volumes of unstructured/semi-structured data
7. Supports replication and partitioning
8. Suitable for big-data applications

MONGODB COMMANDS

// Start MongoDB shell
mongosh

// Select/create database
use college

// CREATE: insert one document
db.students.insertOne({
    rollNo: 101,
    name: "Rahul",
    course: "Computer Engineering",
    semester: 6,
    marks: 82
})

// CREATE: insert multiple documents
db.students.insertMany([
    {
        rollNo: 102,
        name: "Amit",
        course: "Computer Engineering",
        semester: 6,
        marks: 75
    },
    {
        rollNo: 103,
        name: "Priya",
        course: "Information Technology",
        semester: 6,
        marks: 88
    }
])

// READ: display all documents
db.students.find()

// READ: find a particular student
db.students.findOne({ rollNo: 101 })

// READ: condition
db.students.find({ marks: { $gt: 80 } })

// UPDATE: update one document
db.students.updateOne(
    { rollNo: 101 },
    { $set: { marks: 90 } }
)

// UPDATE: update multiple documents
db.students.updateMany(
    { semester: 6 },
    { $set: { year: "Third Year" } }
)

// DELETE: delete one document
db.students.deleteOne({ rollNo: 103 })

// DELETE: delete multiple documents
db.students.deleteMany({ marks: { $lt: 40 } })

// Display database collections
show collections

// Display databases
show dbs
